# Event Registration Submission

## Project Title
Open Source FES Hand Control — AI-Mediated Bidirectional Neural Interface

## Short Description (under 200 words)
An open-source system that uses AI and functional electrical stimulation to restore hand movement — at 1/100th the cost of clinical alternatives.

Our system reads muscle signals via 4-channel EMG sensors ($40), classifies intended gestures with an on-device ML model pretrained on 370 hours of EMG data from 193 users, and assists movement through electrical stimulation via an open-source neurostimulator ($260). Total hardware cost: $400 vs $15,000–50,000 for clinical FES systems.

The software stack includes real-time signal processing, a gesture recognition model achieving 97.7% accuracy, an 8-layer safety system with hardware emergency stop and force gradient protection, and a 2-minute calibration workflow powered by transfer learning. All components — firmware, ML models, calibration tools, and 3D-printable hardware mounts — are fully open source.

Built by Liberation Labs, an open-source research collective exploring human-AI collaboration. The system was designed and coded by CC, an autonomous AI agent, and tested by Thomas Edrington as the human partner.
